# Nxtes feature spec

Nxtes is an open-source (AGPL-3.0) handwriting and PDF annotation app for Android tablets, with a
self-hostable Rust sync server. The goal is feature parity with Flexcil 1.5.0.13 for Android, without
its ads, store or paywall: every feature is free.

**Clean-room rule.** Features are reimplemented from observed behaviour. Nothing is copied from
Flexcil: no code or decompiled snippets, templates, stickers, pen skins, icons, videos, sample PDFs,
UI strings or branding. Nxtes defines its own file format and server protocol.

Priorities: **v1** ships in the first release, **later** comes after it, and **dropped** is out of scope.

| Favourite and recent templates | later |

## 5. Audio

| Feature | Priority |
|---|---|

| One recording synced across several documents | later |

|---|---|

## 7. Accounts, sync and web viewer (Rust server)

| Feature | Priority |
|---|---|
| The app works fully offline; the server is optional and self-hosted | v1 |
| Sign-up confirmed by an emailed verification link; login with email and password | v1 |
| Password reset and email-address change, both confirmed by email | v1 |
| OpenID Connect login | later |
| Device list, removing a device, optional device limit | v1 |
| Sync of documents, folders, trash and recordings; Wi-Fi-only option; progress; live updates from other devices | v1 |
| Conflicts: keep this device's copy, keep the server's copy, or keep both | v1 |
| Per-user storage quota set by the admin | v1 |
| Account deletion | v1 |
| Web viewer: read shared documents in a browser | v1 |
| WebDAV, Nextcloud or Google Drive as sync targets | later |
| A side panel for AI chat sites with drag-and-drop | later |

## 8. Settings

General, viewer, pen, gestures, recording, sync, backup and about screens, plus an exportable
diagnostic log. **v1**

## Dropped

Ads and reward ads, export watermarks, trial and premium tiers, the store and content market,
subscriptions, the Studymini integration, licensed character planners, marketing pop-ups, analytics
and ad SDKs, Facebook and Apple login, pen-toolbar skins, and the early-access programme.
